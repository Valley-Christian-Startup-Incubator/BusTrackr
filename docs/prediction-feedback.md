# Prediction feedback

Riders can judge an estimate from the camera panel in the web app's map view. "The bus is here" is always offered while the feed is current. "Looks wrong" appears only while an estimate is shown. The point is ground truth: each report says what a person saw next to what the system predicted at that moment.

## Record

The worker appends one JSON object per line to `FEEDBACK_FILE` (default `<ALERT_STATE_FILE>.feedback.jsonl`). It never rewrites the file.

```json
{"id":"…uuid…","receivedAt":"2026-11-09T15:08:00.000Z","verdict":"arrived",
 "collector":{"commit":"f15017a","release":"f15017a8c2d1…"},
 "prediction":{"model":"schedule-median-v1","scheduleVersion":"…","status":"estimated","runId":"…","estimatedArrivalAt":"…",…}}
```

- `verdict` is `arrived` (the rider saw the bus at that time) or `wrong` (the shown estimate looked wrong).
- `prediction` is the server's own `/api/shuttle` prediction when the report arrived, not a copy sent by the client. `model` and `scheduleVersion` name the estimator and the timetable.
- `collector.commit` is the worker's `BUSTRACKR_COMMIT`. It stays `null` until the worker is deployed from git (issue #24). `collector.release` is the web app's `bustrackr-release` meta tag, written by the deploy controller.
- `id` is generated by the browser, once per verdict. A retried request with the same id is stored once, across restarts too.

`POST /api/feedback` takes `{"id","verdict","release"}` as JSON. It is rate limited to 10 requests per minute per client IP and accepts the same browser origins as the rest of the API.

## Reading it

`arrived` reports against `estimatedArrivalAt` give a direct arrival error per model and schedule version. `arrived` reports while `status` is `unknown` or `scheduled` point to buses the camera or timetable missed.

```sh
jq -c 'select(.verdict=="arrived" and .prediction.status=="estimated")
  | {model:.prediction.model, errorSeconds:((.receivedAt|sub("\\.\\d+Z$";"Z")|fromdate)-(.prediction.estimatedArrivalAt|sub("\\.\\d+Z$";"Z")|fromdate))}' .data/feedback.jsonl
```
