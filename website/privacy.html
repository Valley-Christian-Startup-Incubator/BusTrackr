Privacy

BusTrackr has no accounts, no ads and no analytics. It doesn't ask who you are or where you are.

Last updated November 1, 2026. This page describes how the software works today.

The iOS and Android apps

  • The app saves one thing on your device: the status URL you connected to, or the sample scenario you picked.
  • It doesn't request location permission and doesn't use GPS.
  • It doesn't save camera observations between launches.
  • It contains no analytics or advertising SDK.

While the app is open, it requests the status URL every ten seconds. The server that answers can see ordinary request details such as your IP address. The bundled 3D scene makes no network requests.

On iOS, the app may ask for local network access if you connect it to a status server on your own network.

This website

This site sets no cookies and loads no third-party scripts, fonts or trackers. The home page requests /api/shuttle from this same server once per page load to show feed status.

The 3D web app

The web app is a separate site hosted by GitHub Pages. GitHub may log visits under the GitHub privacy statement. It also loads fonts from Google Fonts, so Google can see your IP address under the Google privacy policy. The web app's own code sets no cookies and has no analytics.

The status server

Requests to this site and to /api/shuttle reach the server through Cloudflare, which handles them under the Cloudflare privacy policy. BusTrackr's server code doesn't log individual requests or store anything about visitors.

Camera alerts

A camera at the checkpoint emails an alert when a bus enters its zone. Resend receives those emails and notifies the server, which reads each message and keeps only:

  • the camera's event time, the email's date, the time the email arrived, and the checkpoint name
  • a hash of the email's message ID, plus receipt and delivery IDs, used to skip duplicates and retries

The server doesn't store email bodies or attachments in its history. When it must check the signature on a forwarded email, it reads the raw message, up to 2 MB, and doesn't keep it.

The public feed exposes the latest observation, the number of saved alerts and the current prediction. There is no public history endpoint. History stays on the server, with no automatic deletion schedule.

Questions and changes
